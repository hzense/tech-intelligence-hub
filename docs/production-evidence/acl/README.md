## 目录与验收

每次采集以 `<runId>-<runAttempt>/` 单独归档：

- `baseline.json`：来自对应已审批 hosted run 的两份独立采集、匹配指纹和执行 SHA。
- `restore.sql`：基于该基线编写且经审查的恢复方案；未审核不执行。
- `review.md`：来源 run/attempt/SHA、恢复目标核验结论、审查与演练结果、残余限制。

不要预先创建空基线或伪造演练通过记录。恢复脚本不得对生产环境自动执行。
数据库备份留在 Neon；真实备份 ID 和运行审批继续保存在受保护 Environment secrets。
目录名和文件内容不得使用原始备份 ID。
