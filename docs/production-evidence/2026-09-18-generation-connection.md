## 只读预检边界

- 页面：`/admin/signal-generation`，按钮“运行只读连接预检”。
- API：管理员显式同源 `POST /api/admin/signal-generation/preflight`，正文仅 `{}`；匿名、跨源和非法参数先行拒绝。无 GET 执行器、自动预检、自动重试或预取副作用。
- 独立读取连接策略，无需生成开关或 AI 预算；仍要求 Production、专用角色、批准的 pooled 主机／显式端口／数据库、`verify-full` 与 `channel_binding=prefer`。
- 独立 `pg.Client` 建立实际专用凭据连接，验证 Node TLS socket 已加密且证书授权成功，不以数据库后端 TLS 视图代替客户端链路验证。
- 显式只读事务与超时，验证 session/current user、数据库、共享最小权限合约，并执行不返回任何行的列访问探测；最终回滚、关闭连接。同一服务实例合并并发在途请求。
- 只返回六项布尔检查及固定错误码；不返回实际主机、库名、账号、SQL、原始错误或业务行内容。私有禁止缓存。
- 不调用生成任务列表、过期恢复、导入正文读取、AI 凭据读取或供应商模型。
