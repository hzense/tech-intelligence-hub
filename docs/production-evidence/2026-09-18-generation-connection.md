## 只读预检边界

- 页面：`/admin/signal-generation`，按钮“运行只读连接预检”。
- API：管理员显式同源 `POST /api/admin/signal-generation/preflight`，正文仅 `{}`；匿名、跨源和非法参数先行拒绝。无 GET 执行器、自动预检、自动重试或预取副作用。
- 独立读取连接策略，无需生成开关或 AI 预算；仍要求 Production、专用角色、批准的 pooled 主机／显式端口／数据库、`verify-full` 与 `channel_binding=prefer`。
- 独立 `pg.Client` 建立实际专用凭据连接，验证 Node TLS socket 已加密且证书授权成功，不以数据库后端 TLS 视图代替客户端链路验证。
- 显式只读事务与超时，验证 session/current user、数据库、共享最小权限合约，并执行不返回任何行的列访问探测；最终回滚、关闭连接。同一服务实例合并并发在途请求。
- 只返回六项布尔检查及固定错误码；不返回实际主机、库名、账号、SQL、原始错误或业务行内容。私有禁止缓存。
- 不调用生成任务列表、过期恢复、导入正文读取、AI 凭据读取或供应商模型。

## 本地验证

- 预检核心、配置、HTTP handler、既有生成核心以及合成浏览器回归：35 项通过。
- 真实 Next.js 构建后认证／HTTP 回归：23 项通过，1 项可选浏览器测试跳过；覆盖新预检匿名 401、合法管理员无配置 503、跨源 403、非法参数 400、GET 405。
- 全仓默认测试强制无缓存执行：7／7 构建或测试任务成功；默认跳过的原生数据库、解析与可选浏览器场景不计入通过。
- Web 生产构建、typecheck、lint 通过。此批没有实际生产数据库连接或模型费用。

## 生产执行顺序

1. 独立评审，PR CI 通过后合并，同步 main，核对 main CI 与对应 Production 部署。
2. 操作者把既有生成角色凭据保存为 `HZENSE_GENERATION_DATABASE_URL`，仅 Production Secret；不轮换密码，不覆盖 Runtime 或其他角色连接。不把秘密下载到本地。
3. 保持生成关闭，在带有新配置的部署上由真实管理员点击预检，六项全部通过后再进入下一步。失败停在对应边界，不扩大权限或跳过 TLS。
4. 另行确认生成预算、合成输入外发及接收模型；既有解析预算保持不变，不能自动重复授权给 AI。
5. 在明确批准范围内进行一次私有生成，记录任务状态、候选及证据约束、费用和不重复调用结果；不批准事实、不写正式 Signal、不公开发布、不切换网站数据源。

生产结果待实际操作后追加；本地回归、Secret 保存和部署成功均不能替代真实连接或模型验收。
