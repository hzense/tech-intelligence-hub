## 第一阶段：只读范围

入口 `/admin` → **信号只读工作台**：

- `/admin/signals`：按信号 ID 稳定游标分页，标题／ID 关键词筛选；默认每页 25 条，API 上限 50 条。列表展示的是**最新快照**，不是自动认定为“待审核候选”。
- `/admin/signals/[id]?version=N`：固定版本详情，版本历史、时间依据、摘要／研判、领域、证据主张与来源、人物／组织事件关联、核验概要。
- `GET /api/admin/signals?q=...&after=...&limit=...`、`GET /api/admin/signals/[id]?version=N`：同一数据库读取契约；只有 GET，无创建、编辑、审核、发布或生成方法。

页面和 API 均在访问私有数据前独立检查管理员会话。API 拒绝未知／重复／越界参数及跨站请求，实际 Host 必须匹配固定站点，Origin／Fetch Metadata 另行核对；不信任转发头推导站点，也不把 Next.js 规范化后的内部 URL 当作授权依据。响应私有且不缓存、不索引。Preview／Development 不启用生产只读连接。

### 必须区分的状态

1. `latest_snapshot_version`：已保存快照中最大的版本；可能是发布时克隆，不等于待审核版本。
2. `recorded_head`：历史发布／撤回状态记录；即使记录为 published，也不证明当前仍具有公开资格。
3. `current_public_version`：来自 `current_public_signals` 的当前资格结果，不能由旧回执或历史状态代替。
4. `HZENSE_SIGNAL_READ_MODE`：公开网站是否读取上述视图。旧模式时，后台会明确告知资格成立不代表网站已展示。

核验 `expired` 表示候选核验授权期限，不独立决定已公开版本撤回；当前公开资格由依赖 seal 等约束共同决定。人物／组织展示的是**该事件关联**，不是任职历史。

选择旧版本时，正文与关联边来自该封存版本；来源核验状态、实体名称／状态及 seal 失效标记则是 `observed_at` 本次读取时的依赖状态，不是历史原样还原。

### 最小展示与隐私

当前证据只展示主张、支持／反驳／背景关系、来源名称、安全 URL、日期、核验状态。不返回原始 excerpt、locator、content_hash、原始文档、metadata、完整核验报告／seal、操作者身份、任务授权、租约或 AI 凭证。不是完整的原文审核界面。

URL 只允许无凭证、无查询串、无片段的 HTTPS 链接；不安全链接隐藏，不抓取链接预览。React 按文本渲染内容，不把材料当作 HTML 或执行指令。

详情每组最多返回 50 条，额外记录会显示截断提示；长文本亦有长度限制及提示。未配置、不可用、确实为空和不存在的版本分别显示，**不会回退 Seed 或填充示例记录**。

本阶段仅支持站内规范信号 ID（小写字母、数字及单个连字符分隔，最多 200 字符）。如果数据库返回非规范 ID，工作台显示数据不兼容状态，不输出不可导航的详情／游标、不悄悄过滤或自动改写记录。

| 层                     | 文件                                                  |
| ---------------------- | ----------------------------------------------------- |
| 页面                   | `apps/web/app/admin/(protected)/signals/`             |
| 展示组件               | `apps/web/components/admin-signal-workbench.tsx`      |
| HTTP／参数／配置边界   | `apps/web/lib/admin-signal-workbench-core.ts`         |
| 生产只读连接           | `apps/web/lib/server/admin-signal-workbench.ts`       |
| SQL 查询和最小返回字段 | `packages/database/src/signal-workbench-store.mjs`    |
| 精确权限校验           | `packages/database/src/signal-workbench-contract.mjs` |
| 授权 SQL               | `db/roles/configure_signal_admin_reader.sql`          |

不新增业务表迁移。功能最低要求为 `0012`；当前部署前需独立确认生产仍符合已交付的 `0013` 完整 Schema，并新建专用
`hzense_signal_admin_reader` LOGIN／NOINHERIT／非特权角色（连接上限 2）。
不能借用 owner、migrator、AI 管理员或 Publisher 凭据。
授权 SQL 仅面向经过核对的全新空角色，授予规定列 SELECT、数据库 CONNECT、public USAGE
及当前公开资格所需的一个只读函数；发现未知权限、成员关系或对象则失败，不擅自扩大其他角色权限。

生产配置名是 `HZENSE_SIGNAL_ADMIN_DATABASE_URL`，使用 Neon pooled 地址、专用角色密码、显式端口，
`sslmode=verify-full&channel_binding=prefer`；复用 `HZENSE_RUNTIME_EXPECTED_*` 核对数据库目标，
不复用 Runtime 的实际连接凭证。只在 Vercel **Production** 保存为 Secret，禁止进入仓库／聊天／日志。

每个进程连接池最多 1 个连接，空闲 10 秒退出；每次读取先开启
`REPEATABLE READ READ ONLY`，设定语句／锁／事务空闲超时，然后核验实际身份及有效列／表／函数权限。
任何异常只返回固定错误类别。生产尚未配置时显示“尚未配置”，不得报告该工作台已经可读生产数据。
