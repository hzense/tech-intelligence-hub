## 如何理解核验状态

| 状态                     | 含义                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------ |
| `page_located`           | 检索可返回对应首选页面、标题或内容；不保证已读到完整付费正文，也不保证全部数字正确。 |
| `alternate_page_located` | 原链接读取失败或被替换后，定位到相关备用报道；不是独立交叉验证。                     |
| `partial_support`        | 已有页面只覆盖候选的一部分，其他子主张、回应或交易阶段待补。                         |
| `access_blocked`         | 当前检索未能读取目标文章；并非认定链接不存在或事件虚假。                             |
| `version_conflict`       | 原文版本或标题与正文口径存在需要解决的差异。                                         |
| `snapshot_required`      | 动态页面可读，但不能证明材料所述历史版本。                                           |
| `indexed_only`           | 检索索引存在内容，但直接打开失败，不能当作实时原文已验证。                           |

这里的“页面已定位”不是 HTTP 健康监控结果：浏览检索工具可能使用缓存，未保存整篇正文或声称取得版权授权。转载仅说明可追溯路径，不自动视为独立新闻源。

## 来源登记策略

- `source_id_suggestion` 标识首选 URL 的发布/承载方；转载的原作者归属在核验注记中说明，不把 Investing.com 的网页伪装成 Reuters 域名。
- `allowed_hosts` 尽量限定实际使用的机构域名或子域，不添加通用 `x.com`、`gov.cn`、`q4cdn.com` 白名单。
- Alphabet 财报使用材料已引用的 `s206.q4cdn.com/479360582/...` PDF。白名单机制只能限制主机，不能限制租户路径；本条核对了文档身份，但不能据此把该主机上的所有文档视为 Alphabet 公告。
- 新增官方来源的 `trust_score` 为 90–95，新闻及研究来源为 80–90，延续现有登记尺度。这是可调整的来源级编辑权重，不是这 102 个事件的真实性概率；没有填写候选的 `confidence` 等分数。
- `active: true` 仅启用来源登记。它不绕过 Signal 的内容审核，不使本目录候选自动上线。
