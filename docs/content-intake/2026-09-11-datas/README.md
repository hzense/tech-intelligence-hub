## 数据含义与审核边界

- 本批采用独立的 `hzense-document-signal-intake-v1` 审核资料格式，**不是**生产 `data/seed/signals.yaml` 的可直接导入版本。候选的内容状态全部为 `accepted`（已接受），核验标记为 `document_only`（仅依据材料），即内容已接受但逐项事实核验尚未完成；来源定位结果另见 `source_check`。该批次记录时，网站及生成器不加载本目录。
- `reported_event_date` 是从材料提取的事件 / 公告 / 报道日期建议，不是已核实的发生日期；有 8 条暂缺日期。初次提取时 `occurred_at` 全部留空；现已为导入的 66 条补充核对后的日期，36 条仍留空。
- `captured_at` 为本批整理采集时间 `2026-09-11T21:15:59Z`；不回填历史日期。历史线索不能因此自动变成当天新闻。
- `provenance.cited_urls` 保留材料原引用，`source_url_suggestion` 已按该批次的来源检查作部分替换；一个段落内的背景链接不必然支持该候选。主页、栏目页和动态排行榜须补精确原文或版本快照。
- `source_id_suggestion` 已全部按扩充后的来源域名白名单匹配；原先 90 条未匹配的问题已解决，但域名匹配不是逐项事实核验通过。
- `type_suggestion`、`topics_suggestion` 分别是类型和主题的整理建议。自动驾驶、商业航天使用已有分类节点，但自动驾驶的主题种子数据已随该批次正式导入补充；商业航天在该阶段仍未新增映射。
- 候选提取字段 `importance / strength / confidence / novelty`（重要性／信号强度／置信度／新颖度）保持留空；正式种子数据的编辑评分与依据另存导入台账，不伪称客观测量。类型 `research`（研究）在此包含研究报告，不自动代表同行评审论文。
- `event_key_suggestion` 是暂定去重键，不是最终事件身份。已做明确跨日重复合并；不同公告、融资传闻更新、正式项目公告分别保留。正式入库前仍需语义去重和必要拆分，特别是视频模型多笔融资汇总。
- 边界选择：以当时 HZense 的人工智能、半导体／算力、安全与机器人为主，保留少量直接相关的自动驾驶、航天线索；一般股指、油价、战争、宏观和纯预测未作为技术事件逐条录入。这不是对全部综合新闻的穷尽式入库。
