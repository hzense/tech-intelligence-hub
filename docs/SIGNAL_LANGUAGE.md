# 信号中文规则

信号的标题和摘要必须分别以中文叙述为主。原始新闻是英文时，也应忠实译写成中文；不能把整段英文新闻直接当作信号正文。标题仍最多 80 个字符，摘要仍最多 500 个字符。

允许保留英文人名、组织名、产品名、型号和技术术语，例如 `OpenAI 发布 GPT-6`、`NVIDIA 发布新款 GeForce RTX 5090 显卡`。翻译不能增加原文没有的事实，也不能删去不确定性和限定条件。

## 生成与发布

- 后续生成任务使用 `signal-chinese-v1`，继承事件类型、原文发布日期、资源和逐字证据规则。服务端将中文要求加在配置提示词之后；原有模型配置不必重建，也不能通过自定义提示词取消中文要求。
- 标题、摘要各自进行确定性检查：至少两个汉字，通常要求汉字数不少于外文词单元数；常见英文新闻谓词额外计权，避免英文句子只附加几字中文就通过。数字和标点不参与比较，英文按词而非字母长度计数。对 `NVIDIA 发布 Open Agent Safety Platform` 这样的短标题，允许明确中文事件短语搭配多词英文专名。此检查结合中文提示词执行，不能代替语义翻译、专名识别或事实核验；含糊的短标题应补足中文叙述。
- 语言不符合要求的新生成项不能成为可用候选；安全诊断指出标题或摘要需要中文，不自动重试或额外调用模型。其他合格候选仍可按原流程处理。
- 人工确认发布、自动发布以及旧 v3 新发布均检查中文要求。英文标题或摘要可以保存为待修改草稿，发布前必须改为中文。后台显示缺少中文标题／中文摘要的原因。
- 当前 Seed 内容加载也执行此规则；归档结构解析保持兼容。

## 原文与历史记录

证据 `quote` 必须保留原始语言、大小写和标点，确保能在原文中逐字核对。人物和组织原名、来源标题、模型 ID、URL 及字段标识不受正文中文比例要求限制。

旧生成任务仍按创建时的契约解释。既有英文候选可继续查看、补充资源或修改发布草稿；成功回执重放、历史材料哈希和撤回保持原行为。此次规则修改不翻译或覆盖已保存的候选、已发布正文及证据；已有英文信号需通过正常修订发布流程改为中文。

无需新增数据库迁移、角色授权、模型或预算配置。代码部署后适用于后续新任务及新的发布操作；本地测试通过不代表线上已启用。
