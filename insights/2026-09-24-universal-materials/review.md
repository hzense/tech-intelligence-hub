# 开发评审与验证记录

2026-09-24，生产未变更。

## 评审发现与修正

- 历史列表截断不能决定材料资格：新增按报告标识/计划摘要精确读取，以及按已核验回执时间选择权威报告。
- 摄入签名临近过期：保存事务以数据库 transaction_timestamp 与 received_at 默认值同源验签；回放按原签名、原接收时间验证。
- 维护并发可能改变来源/领域：新增只锁定已存报告依赖的受限函数；不为获取行锁扩大登记角色的更新权限。
- 前十条证据不足请求占满队列：增加显式游标分页，不伪造成功或自动丢弃旧任务。
- 私有正文与公开出处同文：允许一份合法 URL 补出处，保留逐字引文、容量及补充资料去重约束。
- 补证包已有全部证据却重读导入服务：仅报告实际使用原件 URL 时严格核对；worker 的原 URL 是可选上下文，读取失败不破坏补证包。
- 确认可读性：显示摘要、日期、人物角色、组织、领域、逐条主张及可展开原句；同候选身份重试、请求超时不自动重发。

独立代码复核在上述修正后未发现未解决的 P1/P2；这个结论不代替真实数据库或生产验收。
