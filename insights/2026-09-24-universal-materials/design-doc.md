# 通用候选补证与正式材料登记设计

2026-09-24 · 开发中 · 本次不部署生产

## 1. 背景与目标

[事实] 现有补全只能提出原快照中的日期、人物、组织；实体目录和公开证据匹配失败后，没有通用登记入口（见 sources.md）。

目标：任何有效私有候选均可建立版本化补证请求、关联最多三份当前用户的已解析资料、接收独立材料核验报告、确认登记并重新运行既有发布准备。标题、摘要、主张保持原候选内容；新增来源只能补依据和关系，不能借补全悄悄改写事实。

非目标：不自动发布、不放宽人物要求、不允许 AI 自签事实通过、不扩大已有 reader/reviewer 权限、不覆盖原生成结果与账本。自动联网搜集和独立核验服务的部署不是本次生产操作。

## 2. 约束与假设

- 管理员只选择已有资料并确认；后台生成技术 ID、摘要和引用映射。
- 新补证包保留原片段，新增片段重编号，保留资料、fence、hash 与来源 URL 声明；URL 声明不是公开许可。
- [假设] 独立材料核验方可以消费版本化请求并回传签名计划；服务未配置时明确等待，不能产生假成功。
- 原人物/来源缺失时不猜测负责人。事件参与者可以来自补充来源，但必须有逐字身份依据及独立事件关联核验。

## 3. 方案比较

| 方案                               | 一致性                          | 安全性                                 | 代价                       |
| ---------------------------------- | ------------------------------- | -------------------------------------- | -------------------------- |
| 改写原生成快照                     | 破坏历史来源和原哈希            | 旧确认可能指向新正文                   | 修改链路少，但无法可靠追溯 |
| 独立补证包、签名材料报告、登记回执 | 原候选不变，新材料单独绑定 hash | 原文真实性、许可和实体身份必须独立核验 | 新私表、专用角色和核验协议 |

采用第二种。原 AI 补全可继续使用；新流程无需为了提交补证请求再次调用付费模型。

## 4. 流程与职责

`候选 + 已解析资料 → 私有补证请求 → 独立材料核验报告 → 管理员确认 → pending 登记 → 核验状态回执 → 既有审核/转换/信号核验/发布`

- `sourceBundleHash` 绑定独立的合成原文及 provenance；`baseMaterialHash` 永远绑定原候选。
- `planHash` 绑定来源、摘录内容 hash、人物/组织、领域与主张映射；签名协议为 `signed-material-verification-v1`，不复用只能验证已转换 Signal 的旧协议。
- 独立核验须逐项说明来源真实性、使用许可、实体身份、事件关联、主张支持和分类。签名只证明报告来源，核验方仍须真实执行这些检查。
- 登记角色不能 INSERT verified 证据，也不能 UPDATE 核验状态；另一个角色仅提升签名报告覆盖的证据状态。两个事务之间失败时保留 pending，不公开，原请求可对账续行。
- 现有目录只做精确复用；ID/类型/内容冲突或姓名歧义拒绝，不覆盖已有记录。领域只接受现有已启用 Taxonomy。
- 原候选正文、删除状态、owner、签名及材料 hash 在每个写入边界复核。GET 不写入。无效或旧网页确认拒绝。

## 5. 上线与回滚

追加迁移和独立角色脚本；旧角色授权保持不变。默认关闭新写入。先测试合成数据，再经用户批准迁移/授权/配置；最后执行独立验收。关闭新开关停止创建、核验摄入与登记，历史仍可查看，不删除审计。

## 6. 风险与反面观点

最强反对意见：独立核验服务尚未配置时，新页面仍不能让候选全部变绿。这个限制属实；不能用一个“确认”按钮代替真实性和使用许可核验。页面必须说清“待材料核验”与“待登记”。

主要风险：恶意来源的提示注入、重放签名、跨用户补证、同名实体误绑定、资料过大、登记部分成功、公开证据后来撤销。缓解分别是只把原文视为资料、绑定短摄入窗口和全计划摘要、owner/fence 校验、拒绝歧义、输入硬上限、分阶段幂等回执和发布前重新读取依赖。

## 7. 自评与验收

问题定义与替代方案已明确；正确性和安全性以合同测试、存储事务测试、真实 PostgreSQL 迁移/角色测试、管理员接口与浏览器测试为准。尚未运行的测试、生产配置或外部核验服务不写成通过。
