- 产品发布与第三方研究各为不同事件：Cerebras CS-4 发布和后续研究、PORTS-Pike 公告和 NVIDIA backstop 研究不混成一条。

- 深挖具名发言人、研究作者、客户测试者及研究对象，并区分他们的角色。例如 ASML 与 TSMC 的公告发言人、Accenture 的联合稿发言人、ClusterMAX 的被评测云厂商；媒体平台仍仅作为来源。

## 边界与规则

- 一条 Signal 表示一个可区分的事件或研究发布；`type` 是唯一枚举值，`topics` 是可包含多个规范 Taxonomy ID 的数组。
- 事件日、公告日、报告发布日期与采集时间分开。只有日精度的日期以 UTC 零点存储，不声称知道准确时刻。
- 新候选标题不超过 80 个 Unicode 字符、摘要不超过 500 个；沿用当前 Seed 契约和来源域名白名单，禁止恢复 `strength`。
- `confidence` 是新闻可信程度的编辑估计，不是模型性能、项目成功概率或统计置信区间。
- 人物、组织必须有可说明的关联角色。研究作者与研究对象可以关联，但不得冒充项目实施人；媒体和研究平台仍放在来源字段。
- 暂缺人物、组织、精确日期或原始依据的线索单列待核验，不用公司高管或采集日期凑齐。
- 当前会话没有可调用的 ChatGPT 原生 Deep Research。采用并行全文审读、网页原始来源核验与可复跑结构校验；不声称已运行该产品功能。
