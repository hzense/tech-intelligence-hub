# 批量导入中心：第二阶段设计与首个增量

**日期：** 2026-09-15

**状态：** 设计拆分与接收前校验开发；不是完整导入功能或生产上线记录。

目标是让管理员把文件与链接混合提交为可追溯、可续跑的私有批次，后续再交给 AI 生成与合格发表链路。本记录服务于开发、代码评审和生产配置审批，不改变现有产品范围。

- [设计与交付边界](design-doc.md)
- [来源与核对依据](sources.md)
- [评审记录](review.md)
- [接收前校验包](../../packages/ingestion/README.md)
- [六阶段进度](../../docs/SIGNAL_WORKBENCH.md)

本增量只校验声明的文件信息、混合批次限制、逐行链接和已配置能力。没有读取原文件、发出网络请求、建立批次、生成上传凭证或调用 AI；返回 `valid` 不代表真实文件安全、已接收、已解析或可发布。

推荐的生产组合为现有 Neon、Vercel 私有 Blob 与线上隔离解析 Worker；技术组合已向操作者提出确认，创建资源、OCR 供应商、费用和最小授权另行确认。即便批准组合，也不意味着某个 Worker 产品或付费 OCR 已获准投产。
