# 私有资格检查与原子发表

本轮目标是把已封存候选的已记录资格检查、新版本组装、发布控制和 Outbox 写入放进同一事务；不是开放生产 Publisher。

- [设计与自评](design-doc.md)：范围、替代方案、锁序、风险与未完成事项。
- [来源清单](sources.md)：仓库契约与 PostgreSQL 一手资料。
- [实施契约](../../docs/SIGNAL_QUALIFIED_PUBLICATION.md)：接口、验收结果与交付状态，随实现完成更新。

当前设计不把结构／核验状态检查当成事实正确或可长期公开的证明。数据库入口不包含模型调用、公开路由或生产授权。
